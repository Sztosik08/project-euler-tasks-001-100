# project-euler-tasks-001-100
Repository to track progress of project euler problems. Solutions for problems 001-100 are shared.

Purpose of starting this repository is to maintain the ability to write code and reason without AI. 

# Project Euler Solutions

My solutions to [Project Euler](https://projecteuler.net/) problems, written in Python.

Each problem lives in its own folder with the solution code, a short explanation of the approach, and any input data it needs.

## Structure

```
problem-001-multiples-of-3-or-5/
  solution.py
  notes.md
problem-002-even-fibonacci-numbers/
  solution.py
  notes.md
```

The original combined notebooks (10 problems per file) are kept in `notebooks/` for reference.
